## pnpm workspace 发现坑（ERR_PNPM_WORKSPACE_PKG_NOT_FOUND）
- 现象：用户重跑 `pnpm install` 报 `@zpackage/web-package` 在 workspace 找不到（zp-utils-package 依赖它）。
- 根因：pnpm 对 `pnpm-workspace.yaml` 里的**非通配 glob（如 `'web-component'`）不会递归子目录**——它只把 `web-component/package.json`（name=`@zpackage/web-package-docs`）当成唯一包，不会自动发现 `web-component/packages/package.json`（name=`@zpackage/web-package`）。`pnpm list -r` 验证：缺失的就是这个嵌套包。
- 修法：在 `pnpm-workspace.yaml` 显式加 `web-component/packages`（与 `web-component` 并列）。加完 `pnpm list -r` 即出现 `@zpackage/web-package@1.2.26-beta.42`。
- **重要约束**：`web-component/docs`、`web-component/example`、`web-component/internal/build` 这三个目录不可纳入 workspace——它们依赖 `@element-plus/build`、`@element-plus/metadata`、`@element-plus/build-utils`、`@element-plus/build-constants`、`@element-plus/docs` 等**element-plus 原 monorepo 内部包，本仓库没有**（扒源码时只扒了 `packages/` 运行时库）。这些 `workspace:*` 引用会触发 WORKSPACE_PKG_NOT_FOUND。它们属 element-plus 文档站构建工具链，与"消费组件"目标无关，刻意不纳入。
- 已核对：所有**已进入 workspace 的包**里的 `workspace:*` 依赖均能解析（@zpackage/{tools,custom-dagre,web-package} 都存在）；`@element-plus/*` 悬空引用只存在于未纳入的 docs/example/internal/build。
- 结论：根目录加 `web-component/packages` 后，用户可重跑 `pnpm install`，不会再撞 workspace 找不到的错。

## ERR_PNPM_SPEC_NOT_SUPPORTED_BY_ANY_RESOLVER（got yarn 补丁）
- 现象：`pnpm install` 报 `got@patch:got@npm%3A11.8.2#~/.yarn/patches/got-npm-11.8.2-c1eb105458.patch isn't supported by any available resolver`，上下文是 `web-component`。
- 根因：Yarn berry 的 `patch:` 补丁协议（补丁文件指向 `~/.yarn/patches/`，即用户 HOME 绝对路径，本机不存在）。来自 `web-component` 依赖树里某个**已发布的 npm 包**（高度怀疑 `@dcloudio/uni-cli-shared` 等 element-plus 文档/uni-app 工具链——它们用 yarn berry patches）。pnpm 不认 yarn 的 `patch:` 协议，且补丁文件又不存在 → 报解析器不支持。
- 全仓（package.json / pnpm-lock.yaml / home 的 .npmrc .yarnrc.yml / 父级 package.json）都搜不到这个 spec，确认是**依赖传递链里某发布包的 `resolutions`**，非本地配置。
- 修法：在 workspace 根 `package.json` 加 `pnpm.overrides: { "got": "11.8.2" }`（就是补丁基底版本，只是不带坏掉的 yarn 补丁），强制 pnpm 把 got 解析成纯净 11.8.2，绕过补丁。
- 残留风险：可能还有别的 yarn-patch 包（docs/uni-app 工具链特有）。若重跑又撞同类错，要么继续加 overrides，要么把 `web-component/package.json` 里 docs/uni-app 专属的 devDependencies（`@dcloudio/uni-cli-shared`、`viteprit` 等，构建组件库用不到）删掉。
