## 修复：表格空白 + 新增无效
- 根因：VxeTable 用 `height="100%"` + `scroll-y` 虚拟滚动，父链百分比高度解析为 0 → 虚拟滚动可视区 0 行，全表空白；因表格未渲染，"新增"追加的行也不显示（同源问题，非数据逻辑错）
- 修复：用 ResizeObserver 实测 `.dt-grid` 像素高度写入 `gridHeight` ref（初始兜底 560），VxeTable 改绑 `:height="gridHeight"`（数值）并加 `:auto-resize="true"`；`.dt-grid` ref 为 gridBox，mount 时 nextTick(syncGridHeight) + observe，unmount disconnect
- 验证：dev server(5181) 重编译该 SFC HTTP 200 无报错；columns 7 列定义完整、addRow 走 allRows.value.push 响应式正常
