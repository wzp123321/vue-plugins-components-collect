## Tabulator 录入台 · 控制台报错修复（同日追加）
实机 CDP 复现后确认是三处运行时 API 误用，已全部修正并实测：
- **延迟建表**：`new Tabulator()` 内部 `setTimeout(() => this._create())`，构造返回时 `initialized=false`，
  此刻 setData/setColumns/redraw 会刷 "Table Not Initialized" 并在数据加载器里炸。
  → `init(el, onBuilt?)`，首屏装配挂 `tableBuilt`；其余触碰实例的方法统一 `ready.value` 守卫。
- **表级没有 `reformat()`**（只有 `RowComponent` 有）→ 之前 `table.reformat()` 必抛
  "reformat is not a function"。改为逐行 `getRows().forEach(r => r.reformat())`；
  ambient d.ts 里那条 `reformat()` 声明是元凶（谎报 API），已删除。
- **`titleFormatter` 签名是 (mockCell, params, onRendered)**，不是 (title, titleEl)；
  且**必须返回字符串/Node**，返回 undefined 时 `Column._formatColumnHeaderTitle` 会把表头 innerHTML 清空。
- **单元格 formatter 返回值直接进 innerHTML** → 补 escapeHtml，否则 `<` 被当标签。
- **行基础底色**：Tabulator 默认 `.tabulator-row{background-color:#fff}`，暗色下不覆盖就是白带。
  必须显式 `background-color: var(--bi-panel)`，斑马/hover/选中再各抬一级优先级。
- 冻结列类名是 **`tabulator-frozen`**（不是 `.frozen`）；官方已是 `background-color:inherit`，
  能自动跟随行斑马/hover/选中，只补分隔线即可。
实测：首页 200 行、8 列表头（必填红星）、虚拟滚动 20 行、点格编辑→改动 1→Ctrl+Z 回 0，控制台无 error/warning。

## Tabulator 录入台 · 交互对齐另三套（A+B+C 全量补齐）

用户问「交互较另外三个是不是没完全实现」→ 核对源码后确认：**不是 Tabulator 没能力，是没接模块**。
`SelectRange`(含 FillHandle) / `Clipboard` / `Keybindings` / `Menu` / `Filter` / `Sort` 全是内置。
用户选定「全量补齐（含右键菜单）」，已落地并实机验证。

**硬约束（改架构级）**
- **`selectableRange` 与 `selectableRows` 互斥**：`SelectRange.initialize()` 里检测到行选择就 `console.warn` 且不初始化。
  要矩形选区必须去掉行选择，行操作改由「选区 → 行集合」推导。
- **行身份统一用 `rowId`**（`index:'rowId'`，复用 `utils/bi-entry.ts` 的 `META_FIELDS` 口径）。
  高亮键从「行号:字段」改成「rowId:字段」，一次解决排序/筛选后错行 + 选区跨不连续行两个问题；
  对外仍暴露 0 基下标（`markErrors`/`markFind`/`selectionOrigin` 调用面不变，内部经 `idIndex` 反查并 sort）。
- **`Row.updateData()` 是原地写**（`this.data[k]=v`）→ `writeRecords` **不能** `records.map(r => ({...r}))`，
  否则粘贴/填充改的是 Tabulator 的副本，真相源失联。用 `records.slice()` + `ensureRowIds`。
- 批量写入（填充柄 / 粘贴）只发 `rowUpdated`，**不发 `cellEdited`** → 必须另接 `rowUpdated` 合并刷新，
  否则状态栏「改动/选中」永不动（真 bug，已修：`setTimeout(0)` 合并 + `refreshSelection()` + `bump()`）。

**选项级坑**
- `clipboardCopyRowRange` 默认 `'active'`（整表 + 表头）→ 改 `'range'` + `clipboardCopyConfig:{columnHeaders:false}`，
  否则 Ctrl+C 复制出一整张表。
- 列头筛选只监听 `keyup` / `search` / `change`，**不监听 `input`**（CDP 里派发 `input` 会得到「筛选无效」的假象）。
- `frozen` + `selectRange` 会刷 `Using frozen columns that are not the range header ... unpredictable behavior`。
  该判定只对行选择模式成立，此处是误报 → 不用 `frozen`，改 `cssClass:'tb-pin-col'` + 自写 `position:sticky`
  （Tabulator 的 frozen 本来就是 sticky 实现）。
- **排序箭头颜色压不动**：官方选择器
  `.tabulator .tabulator-header .tabulator-col.tabulator-sortable[aria-sort="descending"] .tabulator-col-content .tabulator-col-sorter .tabulator-arrow`
  特异性 **0,8,0**；只写 `.tabulator-col .tabulator-arrow` 完全无效（实测仍是 `#666`）。
  必须照抄整条路径再加 `.tb-page` 前缀。方向判定看 `aria-sort`（不是 `tabulator-col-sorted`，v6 已无此类名）。
- 录制右键菜单要在 `.tabulator` 上挂 `contextMenu`；Menu 弹层 append 到 body（在 `.tb-page` 外）拿不到 `--bi-*`，
  用字面色 + `html.dark` 分支。
