# 2026-11-01 三套录入台样式对齐与一致性收尾

用户四问：① Univer 表格样式更好看点 + 三套是否参考有数BI？② 三套暗黑/白天 + hover 是否都没问题？③ 有问题直接采用最好建议，不用问；④ 开发完提交代码。

**Q1 样式来源（明确回答）**：三套共用项目内部色板 `--bi-*`（数据平台克制风格：冷灰底+白面板、1px 细线、不靠渐变/彩色投影），**未参照有数 BI 或任何具体产品令牌**。刻意如此——保持三套一致且无第三方授权风险；要换成某产品风格需用户提供其色板令牌。

**Univer 样式对齐（核心改动）**：原先 Univer 只 `toggleDarkMode`，画布仍走内置默认色（与其余两套观感不一致）。现注册品牌主题：
- `useEntrySheet.setDark(dark)` 整体 `setTheme({...defaultTheme, gray, primary, highlight})`，`gray`/`primary` 由 `--bi-*` 明暗两档映射（灰阶 0≈画布底/100≈表头底/400≈网格线/800≈正文；品牌尺 500=选区主色；highlight→查找高亮橙底）。
- `defaultTheme` / `Theme` 类型由 `@univerjs/presets` 透传（`export * from '@univerjs/themes'`），**无需新增依赖**（themes 包本就作传递依赖存在，未 hoist）。
- ⚠️ `setTheme` 是整体替换（ThemeService 不合并），必须全量透传 `defaultTheme`；`toggleDarkMode` 只发事件、不复写主题，与 `setTheme` 各管一层。

**VTable 主题补齐**：`buildTableTheme()` 原只配 default/header/body/frame，缺 hover/选区。补上 `defaultStyle.hover`(行高亮)、`select`+`selectionStyle`(选区双向淡色底+品牌描边)、`scrollStyle`、`functionalIconsStyle.sort_color`(排序图标品牌色)，全部从 `--bi-*` 取。暗黑靠 `watch(themeStore.isDark)→rebuild()` 重建主题。

**校验**：vue-tsc 0 error；eslint 0 error（改动文件）；check:nav（146/105/73）、check:components、stylelint 全绿。
