## 3D 地图：顶面提亮 + 侧壁明度阶梯

用户反馈「地图颜色稍微亮一点，侧壁颜色完全看不出，感觉 3D 地图就像 2D」。

- **根因（客观复算）**：系统 Temp `map-depth-probe.cjs` 复现 `regionSurfaceTexture` 算法，用 luma = 0.2126R + 0.7152G + 0.0722B 量化。改前顶面暗端 P10 `L=47.3`、侧壁顶 `L=47.4`（几乎相等），侧壁底 `L=14.7` 又贴着背景 `L=5.0`（差 9.7）——侧壁两头都糊掉，所以读成 2D 平片。不是厚度不够，是三级明度没有断层。
- **规则**：顶面 > 侧壁 > 背景；侧壁顶须比顶面暗部再低一档、侧壁底须明显高于背景。侧壁由 `ShaderMaterial` 直出 hex、不受光照，顶面是 Phong 的 `map × color`，两者不在同一受光模型，调色时不能直接拿 hex 互比。
- **改动仅 `utils/mapConfig.ts`**：`surfaceGradient.dark #1C3A30→#345F50`、`sideColorTop #123831→#16453C`、`sideColorBottom #04120E→#0B211D`，并同步 `themePalettes.dark`（`ChinaMap3D.vue` 的主题 watcher 是 `immediate`，setup 期间经 `layer.setTheme → applyTheme` 覆写 `mapConfig`，只改默认值首帧会被盖回）。`light`、`gamma / baseGain / highlights` 不动——`dark/light` 只参与最后的颜色映射，不参与 `level` 计算，故 C 反解出的分布形态（暗层约 38%、越亮越少）保持不变。
- **复算结果**：顶面 P50 `76.6→98.7`、P99 `203.5→203.7`（亮端不炸）；顶面暗端−侧壁顶 `-0.1→+16.0`（倒挂消失）；顶面 P50−侧壁顶 `29.2→40.3`；侧壁底−背景 `9.7→23.0`。
- 零几何 / 零 shader / 零 draw call 改动。`depth=6` 未动（牵动 `lineZ / spotZ` / 相机 / 拾取，属形态）；`sideEdgeGain` 仍 0（顶边细亮线未开）；`themePalettes.light`、飞线轨道 `trackColorNear #123831`（独立装饰色）、藏南边界可见性均未动。
- 侧壁材质是模块级单例、uniform 在建模时写入，必须 `Ctrl+F5` 强刷。`applyTheme` 只改 `mapConfig`、不更新已建材质 uniform，切亮/暗主题时侧壁沿用首次建模颜色（既有缺口，未修）。
