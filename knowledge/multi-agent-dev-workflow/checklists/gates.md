## 熔断规则

| 条件 | 动作 |
|---|---|
| 任一阶段 `round > 3` | 停止，输出分歧摘要，交人二选一/三选一 |
| 任一次 handoff 无 `signal` 回执 | 编排者主动追问，不静默推进 |
| 验收 FAIL | 按缺陷「根因分层」回退对应阶段（契约→Phase 2、设计→Phase 3、需求→Phase 1、实现→Phase 5），**禁止无脑回 Phase 5** |
| 单阶段 token 超 `max_tokens` | 收缩 `context_budget` 只保留 `must_read`；仍超则拆分 handoff，并记进 `cost_log` |
| 契约在 Phase 5 被改 | 强制通知双方 + 标注受影响章节，否则视为流程违规 |
