# Icon 图标

用于展示 icon 图标 。

## 基础用法

:::demo 使用 `name`、`color`和 `size` 来定义图标的样式。

mobile/icon/basic

:::

## Icon 属性

| 属性名 | 说明                | 类型      | 默认值 |
| ------ | ------------------- | --------- | ------ |
| name   | `iconbox`上图标名称 | ^[string] | -      |
| size   | 图标大小            | ^[number] | 16     |
| color  | 图标颜色            | ^[string] | -      |
