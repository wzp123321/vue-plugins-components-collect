# 使用说明

（1）组件版本更新策略

1. 组件版本：分为普通版本和里程碑版本（功能、稳定性较好）
2. 组件更新频率：季度、半年、年
3. 更新策略
- 新建项目：使用最新的里程碑版本
- 有需要使用新组件的项目：更新到最新版
- 其他项目：定期更新到最新的里程碑版本

（2）组件替换策略

- 新建项目：严格使用组件
- 其他项目：新功能开发，TR1评审交互设计，确认哪些需要使用组件，开发按要求执行；已有功能，逐步替换。

（3）组件使用检查

1. 代码review的时候检查
2. TR4交互验收的时候检查
