# 前端脚手架使用说明

### 安装

1. npm配置详见[npm天溯源配置](/zh-CN/guide/quickstart.md)
2. 安装脚手架包
```bash
npm install @tiansu/cli -g
```

### 使用

1. 查看命令帮助
```bash
ts-cli -h
```
2. 创建项目
```bash
ts-cli create xx
```
提供两种项目模版

![Alt text](/images/guide-cli-demo.png)

`ts-mobile-uni`：基于uni框架的移动端项目

`ts-web-vue3`：基于vue3框架的PC端项目
