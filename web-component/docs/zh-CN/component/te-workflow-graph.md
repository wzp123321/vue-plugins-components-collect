## API

### 属性（props）

| 参数名            | 参数类型 | 是否必填 | 说明                                                                                            |
| ----------------- | -------- | -------- | ----------------------------------------------------------------------------------------------- |
| tenantId          | String   | Y        | 租户 id                                                                                         |
| axios             | axios    | Y        | axios 实例，把项目中用于发请求的 axios 对象传进来即可。这样组件里面发的请求就会走项目中的拦截器 |
| processInstanceId | string   | Y        | 流程实例 id                                                                                     |
