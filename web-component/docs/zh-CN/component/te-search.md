## API

### 属性（props）

| 属性名      | 说明               | 类型   | 是否必要 | 默认值 |
| ----------- | ------------------ | ------ | -------- | ------ |
| during-time | 防抖时间，单位毫秒 | number | 否       | 500    |

其余参数同：[Input 输入框](/zh-CN/component/input.md#attributes)

### 插槽（slots）

同：[Input 输入框](/zh-CN/component/input.md#slots)

### 事件（events）

| 事件名 | 说明                 | 接受参数 |
| ------ | -------------------- | -------- |
| input  | 带防抖效果的输入事件 | 无       |

其余参数同：[Input 输入框](/zh-CN/component/input.md#events)
