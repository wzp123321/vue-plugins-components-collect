## API

### 属性（props）

| 属性名       | 说明                                     | 类型          | 是否必要 | 默认值 |
| ------------ | ---------------------------------------- | ------------- | -------- | ------ |
| model-code   | 打印模版编码，从系统配置中心打印配置获取 | string        | 是       | 无     |
| props-config | 模版字段配置项，根据以下示例填写         | object        | 是       | 无     |
| tenant-id    | 租户 Id                                  | string        | 是       | 无     |
| axios        | 封装了 header 头和拦截方法的 axios 实例  | AxiosInstance | 是       | 无     |
| list         | 需要打印的数组对象                       | object[]      | 是       | 无     |

### 模版一（propsConfig）LBP

| 属性名      | 说明                                                      | 类型   | 是否必要 | 默认值       |
| ----------- | --------------------------------------------------------- | ------ | -------- | ------------ |
| fieldValue1 | 指定打印的值为列表对象的某个属性值,原 name 字段           | string | 否       | 不传则读配置 |
| fieldValue2 | 指定打印的值为列表对象的某个属性值,原 code 字段           | string | 否       | 无           |
| fieldValue3 | 指定打印的值为列表对象的某个属性值,原二维码 url 或 base64 | string | 否       | 无           |
