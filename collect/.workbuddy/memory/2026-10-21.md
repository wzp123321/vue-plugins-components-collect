# 2026-10-21

## threejs-china-3d-map 新增四项功能（用户从候选清单中选定全做）

用户先问"3d模型还能提升什么/除3d地图外值得学什么"，随后在已很完整的地图项目上选定 4 个补充功能，已全部实现（vue-tsc 0 报错，vite build 兜底中）：

1. **2D 扁平模式**：`mapConfig.setDepth(d)` 动态改 depth/lineZ/spotZ + `drawRegion.updateRegionDepth` 同步侧壁 uniform；`ChinaMap3D.applyFlat` 重建当前层级几何并贴合取景。控制台加「立体/平面」段按钮（MapControlPanel 新增 `flat` defineModel）。注意 depth 是全局耦合参数，只能重建不能纯 CSS。
2. **URL 深链分享**：`useMapViewport.getViewState/setViewState` 读写相机位姿；页面入口 `threejs-china-3d-map.vue` 解析 `#m=` hash 在 setup 阶段还原 层级(adcode)+机位+视觉开关（theme/showColumn/fillByValue/flat），并加「🔗 分享」按钮把当前态编码入剪贴板。drillByAdcode 现透传 drill Promise 以便 mount 里 await 落层后再 setViewState。
3. **排行榜增强**：数据看板 MapDashBoard 原已有 TOP6（悬浮高亮+点击下钻），本次加「TOP6/TOP10/全部」条数切换（原排行榜面板需求已基本覆盖，故做增强而非新建）。
4. **选中区操作层**：选区统计浮层（`.map-sel-stats`）加「差值高亮」「导出CSV」按钮。`setDiffHighlight(enabled)` 选中区相对全量均值着色（高于青绿/低于橙红）；`exportSelectionCsv()` 导出选中（无选中则整层）CSV 带 BOM。

改动文件：mapConfig.ts、drawRegion.ts、useMapViewport.ts、ChinaMap3D.vue、threejs-china-3d-map.vue、MapControlPanel.vue、MapDashBoard.vue。

**待用户实机验证**（WebGL 不可在此 headless 跑）：扁平模式切换观感、深链打开还原、CSV 下载、差值高亮着色。
