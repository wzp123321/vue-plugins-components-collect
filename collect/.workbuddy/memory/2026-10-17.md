### 关键发现：vxe 单元格区域选取是 pro 功能，OSS 版为空钩

用户反馈"鼠标拖动选中单元格"不生效。深度核查 vxe-table 4.22.4（es/lib/dist 全构建 + packages TS 源码 + npm 全量包）：`getCellAreas/handleKdClAreaEvent/handlePeClAreaEvent` 等 cell-area 方法**只有防御性空引用（`if ($xeTable.xxx)`）、无任何实现**，npm 上也不存在对应插件包（仅有 export-xlsx/render-*/menu/validator/shortcut-key）。即 vxe v4 的"单元格区域选取/复制粘贴/查找替换"是官方 pro 功能，OSS 版配 `mouse-config.area: true` 是静默无操作。结论：**必须自研选区**。

自研方案要点（`hooks/useCellSelection.ts` 新建）：

- 键盘协同：利用"vxe OSS 方向键移动不感知 Shift"的特性——普通方向键由 vxe 移动 currentCell 后 watcher 将选区塌缩为单格；Shift+方向键同样由 vxe 移动，watcher 保持 anchor 不动、focus 跟到新格，实现扩展

## 3D 地图：缩放/拖拽/双击下钻三件套失效修复（Edge CDP 实测定位）

用户报"滚轮缩放不好使、双击下钻没实现、拖拽不移动"。用 Edge CDP（headless+swiftshader，dev 9707）逐项实测定位：

**根因（非加载错误，地图正常渲染）：**
1. **拖拽不移动**：`mapInteraction.ts` 的 hover handler 在"非地图区域"把 `controls.mouseButtons.LEFT` 切到 ROTATE(0)，而 `enableRotate=false` → 从空白区域（中国不铺满画布，很常见）起拖完全无效。
2. **双击下钻不触发/易失效**：`createClickHandler` 用 `hasMouseMoved` 守卫（阈值 8px），手抖略超阈值即吞掉合法双击；且入场动画 `isEntranceAnimating` 若因 GSAP ticker 暂停（hidden 标签）未复位，会永久拦截下钻。
3. **缩放"不好使"**：入场 `onComplete` 把 `maxDistance` 锁成初始距离 → 只能放大不能缩小；且若某次下钻抛错，`runDrillAnimation` 中 `controls.enabled=false` 在成功路径才复位 → 控制器卡死，连带缩放/平移全废。

**修复：**
- `mapInteraction.ts`：彻底移除 `mouseButtons.LEFT` 动态切换（统一静态 LEFT=PAN/RIGHT=PAN/MIDDLE=DOLLY）；删除 `hasMouseMoved` 守卫（双击本身非拖拽，不再误杀）；`createMouseDownHandler` 退化为空实现；移除无用 `controls` 参数与 `OrbitControls` 类型导入。
- `ChinaMap3D.vue`：下钻主体 `runDrillAnimation` 的绘制段用 `try/catch/finally` 包裹，`finally` 必复位 `controls.enabled/minDistance`（下钻绘制异常不再卡死交互）；相机动画 `gsap.to` 的 Promise 加 `setTimeout(1600)` 兜底收尾（GSAP 暂停也能完成）；新增 `finalizeEntrance()`（入场收尾统一函数，2.5× 放宽 `maxDistance` 允许缩小看全貌 + 兜底补 scale + 1.5s 超时强制收尾）；`resetToCountry` 与渲染循环"缩回全国"恢复动画的 gsap timeline `onComplete` 均加 `setTimeout(1300)` 兜底复位控制器。
- 顺带删除临时 dev-only `__c3d` 调试句柄（验证用，已移除）；临时 CDP 验证脚本已清理。

**复验（CDP）**：入场完成 → 滚轮缩放 in/out 均生效；从画布**四角空白区**拖拽也平移 → PAN 生效；双击画布中心 → 下钻 level null→province、subGeoChildren 35→7（省→市），`enabled` 复位 true；下钻后再次滚轮缩放仍可用（控制器未卡死）。vue-tsc 触及文件 0 新增错误。

### 追加（第三轮：选区根因修复 + 去行选中 + 键盘导航自管）

用户怒问"拖动选中怎么还没实现"。**根因：vxe v4 的 DOM 属性名记错了**——`useCellSelection.cellFromEvent` 读 `data-field`/`data-rowid`，而 vxe v4 实际是 **td 带 `colid`（需 `tableRef.getColumnById(colid).field` 换算）、tr 带 `rowid`（= row[keyField] 的 encodeURIComponent，本项目 uid 均 URI 安全可直接等同 __id）**，导致 `cellFromEvent` 永远返回 null、选区从未启动。同根因还波及 useGridMouse 的填充手柄 move/up（×2）与右键菜单降级路径（×2）。

**去行选中（用户要求 1）**：删 checkbox 列与 `.dt-chk`、`row-config.isCurrent`、`mouse-config.selected`（vxe 自带单元格高亮与自研选区双轨）、`keyboardConfig.isChecked`；footerData 前缀去 checkbox 对齐；删 `.vxe-cell--checkbox` 死样式。连带把批量操作从 `getCheckboxRecords` 全量切换到选区语义：ops 新增 `selectionRows`/`selectionCount`，deleteSelected/duplicateSelected/批量填充"选中行"作用域改读 selRect.rowIds；`selectedCount` 从 core 删除；buildCopyTsv 去复选框降级分支；Ctrl+A 改框选整个数据区（sel.selectAll，**不能顺手改 currentCell——watch 会塌缩选区**）。

**键盘导航完全自管**（新发现）：vxe 的 `current-change` 是**已废弃的行级事件**（params 无 column），且 `handleGlobalKeydownEvent` 全部依赖 `editStore.selected`（仅 `mouse-config.selected:true` 时才有值）——原 `@current-change` 绑定实为死代码、方向键同步从未生效。现将 keyboardConfig 的 isArrow/isTab/isEnter/isEdit/isChecked 全关，在 useGridMouse 自研：方向键（Shift 扩展）/Tab（行尾回绕）/Enter（下移）/Ctrl+A/F2/Delete/Ctrl+Enter；激活判定自维护 `gridActive` 标志（vxe 的 focus() 只置内部 isActivated 不做 DOM 聚焦，点击后 activeElement 仍是 body，原 `contains(activeElement)` 判断导致所有快捷键失效）；复制/粘贴事件加输入框 target 豁免（防止劫持工具栏搜索框的剪贴板）。填充手柄锚点从 getActiveCell 改为 sel.focus ?? currentCell（selected 关闭后 getActiveCell 只在编辑期有值）。

**真机验证（playwright-core + Edge，dev :5173）**：拖选 4行×3列 = 12 sel/1 anchor ✓；单击塌缩 1 ✓；Ctrl+A = 84（12 渲染行×7 列）✓；Delete 清空选区全部单元格 ✓；截图确认无复选框列、无行选中高亮。vue-tsc 对 excel-data-entry-vxe 0 错误（全项目 24 错误均为 threejs 演示页遗留，与本次无关）。

## 3D 地图第三轮：飞线亮度 / 柱子分段 / 轨道分段

用户反馈三条：①飞线太亮；②数据柱看着一节一节错位；③飞线轨道飞行过程中也一节一节。

**① 飞线偏亮** —— 白核 1.2×、尾焰 1.05×、头部 Sprite opacity 0.9 + size 3.2，再叠 UnrealBloom，整条线接近纯白。参数收口到 `mapConfig.fly`：
`tailGain 0.4`、`coreGain 0.42`、`headSize 1.5`、`headOpacity 0.32`、轨道色 `#081D2E → #15496F`。所有亮度旋钮现在都在 mapConfig，不再散落在 shader 里。

**② 柱子「一节一节」真因（两层）**
1. `CylinderGeometry(..., 16, 1, true)` 的**每段顶点法线是独立的**，段边界法线不连续；又用 `1 - |n.z|` 做 rim 光 → 每 22.5° 一圈亮度台阶。柱体屏幕上只有 2~3px 宽，这些台阶被压成横向断层。
2. 更根本的：这么细的圆柱，**轮廓是多边形 + 无解析抗锯齿**，无论段数多少都会看到硬边错位。
→ 最终改成 **竖直 billboard 平面**（`PlaneGeometry(1,1).rotateX(PI/2)`，宽沿 X、高沿 Z），片元里按圆柱截面着色：
`body = sqrt(1 - dx²)` 做中间亮两侧暗，`alpha *= smoothstep(1.0, 0.86, |dx|)` 做横向解析 AA；朝向靠 `onBeforeRender` 里 `quaternion.setFromAxisAngle(Z_AXIS, atan2(-dir.x, dir.y))` 每帧绕 Z 转（只转方位角，柱身保持竖直）。多边形从 32 个降到 2 个，且彻底无分段。

**③ 轨道/拖尾「一节一节」真因** —— **Line2 不适合宽发光曲线**。Line2 每段是独立 quad，段长（约 4.7px）与线宽（3.4px）同量级时，相邻 quad 在端点处的宽度方向不一致，接缝缺口/重叠占段长比例极大 → 看起来像一串方块的链条（截图里非常明显）。降低段数只会让折线感更重，提高段数也不会消失。
→ 换成**连续三角带 ribbon**：每个采样点两个顶点（左/右），横向 = `tangent × (camera - point)`，永远正对相机；索引 `(2i, 2i+2, 2i+1)`。顶点色同一份写左右两个顶点，加法混合 + 逐点宽度收细（`0.85 - 0.5·k^0.7`，k = 拖尾进度）形成头宽尾尖的流星形态。相机静止时跳过位置重写（`lastCameraPos.distanceToSquared > 1e-4`）。
**注意**：ribbon 顶点每帧重写，`frustumCulled` 必须关掉；`useFlyLines.clear()` 要 `disposeObject3D`（每条线自带几何 + 头部 Sprite 材质），共享材质靠 `userData.shared` 跳过。

**顺带**：LineMaterial 不再需要 track/streak 两份（`lineMaterials.ts` 只剩省界/轮廓/轮廓光晕三种），`setLineResolution` 同步数组相应缩到 3 个。

**验证**：`vue-tsc` 本模块 0 错误；CDP 放大截图（clip scale 3~6）确认——流星为「白热头 + 收细尾焰」连续光带、轨道连续、柱子为平滑渐变光棒（无台阶无锯齿）；拖拽旋转后 ribbon 朝向跟随相机不变细；双击下钻内蒙古只剩 12 盟市 + 返回按钮 + 面包屑，返回正常；`Runtime.exceptionThrown` 全程为空。

## 3D 地图：入场生长动画（柱体逐根长出 + 流星延后起飞）

承接上一条「加载再顺滑一点」。上一轮只做了建板块的时间切片，柱体/卡片仍是「啪一下全部出现」，这是加载观感的最后一块。

- `spotLayer.ts` 新增 `SpotGrower`（column / cap / cards / baseZ / height / delay / cardSize / cardLift）与 `applySpotGrowth(layer, t)`：按全局 t 写 `column.scale.z`、`column.position.z`、`cap.position.z`、卡片 `position.z` + `scale` + `SpriteMaterial.opacity`。柱高为 0 时柱顶光点正好落在原地面上，天然变成「种子亮点」。
- 错峰：按数值降序分配 `delay = rank/(n-1) * 0.34`，高值柱先长。
- **只改 transform / opacity，不动 visible** —— 否则会与 `applySpotVisibility` 的「选中才显示标牌」规则互相覆盖。
- `useSpotMarkers.build(level, animate = true)`：`animate && showColumn()` 才播 0.95s（`power2.out`），否则直接 `applySpotGrowth(layer, 1)` 到位；`clear()` 里 kill tween，onUpdate 里 `if (layer === target)` 防切层后写旧图层。
- `useFlyLines.build(level, delay = 0)`：`gsap.delayedCall` 延后 `group.visible`，reveal 时把每条 `anim.p` 置 0，流星从起点「长」出来。`clear()` 里 kill 计时器。
- `ChinaMap3D.vue` onEnter：`markers.build(level, !deferEntrance)`、`flies.build(level, deferEntrance ? 0 : 0.72)`；projectData / columnColor 的 watch 传 `false`（数据或配色变更不该整屏重长）。

**验证技巧（重要）**：swiftshader 软渲染下 `Page.captureScreenshot` 单张耗时 **3~6 秒**，比动画本身还长，所以「320ms 连拍」实际间隔 6~10s，永远抓不到中间态。有效办法 = **临时把 `GROW_DURATION` 拉到 12s**，先轮询 DOM 阶段文字（等到 `35/35` 后变空 = 图层建完、growth 开始），再连拍 3 张 → 能清楚看到「种子光点 → 逐根长高 + 卡片淡入 → 接近满高 + 流星起飞」三态。验证后务必改回 0.95。

## 录入台第一批交互补齐（A 组 + B 组共 17 项）

先给了一版「可补充清单」（A 小时级 / B 半天级 / C 需设计），用户回「ab先干」，本轮把 A+B 全做完。

**A 组（Excel 横向维度 + 导航辅助）**
- Ctrl+R 向右填充（useGridKeys，与 Ctrl+D 对称）；Ctrl+Space / Shift+Space 选整列/整行（Excel 标准键）。
- 填充手柄支持**横向填充**：轴向判定用指针位移主轴（|dx|>|dy| 为横向，阈值 4px），不再只看行差；横向按选区每行独立推序列（数字/日期按列差）。
- 手柄**双击 = 填充至参照列末行**：手柄的 pointerdown 用了 `.prevent`，会吞掉兼容鼠标事件 → dblclick 收不到，故自测双击间隔（420ms），拖拽结束清零。
- 列头点击选整列（序号列头 = 全选）。**vxe 事件名坑**：`header-cell-click`（不是 header-click），且 `sort-config.trigger` 必须从 `'cell'` 改 `'default'`，否则点表头会被排序动作抢走；params 里自带 `triggerSort/triggerFilter/triggerResizable` 做守卫。
- 十字高亮：活动格所在行/列淡色，用 `background-image` 而非 `background-color`，才能与 `cell-sel`(!important 底色)/cell-error 叠加不打架；活动格自身跳过（保留 cell-active 白底）。
- 状态栏坐标指示（第 N 行/M · 第 K 列 列名）。
- Tab 到末行末尾自动追加行（虚拟滚动模式才启用；分页模式下新行不在当前页）。
- GridQueryChips：关键词/排序/筛选 chips 可视化 + 逐项清除（清除时同步 `tableRef.clearFilter/clearSort`，否则列头勾选残留）。
