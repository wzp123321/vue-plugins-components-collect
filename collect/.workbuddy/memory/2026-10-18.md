## vite dev server 因「沙箱批量删除拦截」崩溃的修复手法
- 现象：新增 three/examples/jsm/...（如 CSS2DRenderer）等未预打包依赖时 vite 触发 re-optimize，`commit` 阶段要删 `node_modules/.vite/deps_temp_xxx` 下 117 个文件 → 沙箱 SAFE_DELETE_BULK_CONFIRM_REQUIRED（单 turn 上限 50）→ node 抛错退出，dev server 挂掉。
- 修法：**不要去删**，用 `mv node_modules/.vite/deps_temp_xxx E:/tmp/...` 把整个临时目录一次改名移走（rename 不是删除，不触发守卫），再重启 vite 即可重新优化成功。
- 判断依据：vite 日志最后一行 `✨ optimized dependencies changed. reloading` 后紧跟 stderr 的 safe-delete 报错，就是这一个原因。

## 修复：CSS2D 标签黑字（scoped 样式命中不到动态 DOM）
- 现象：切到 CSS2D 标签模式时，城市标签是黑字（浏览器默认样式）。根因：`useCss2dLabels` 用 `document.createElement` 动态建 div 再 append 到 `CSS2DRenderer.domElement`（组件根之外注入），而标签样式写在 `ChinaMap3D.vue` 的 `<style scoped>` 里——scoped 属性选择器命中不到这类动态节点，于是回落默认透明底+黑字。
- 修法：把 `.map-c2d-label*` 三规则从 scoped 块移到文件末尾**非 scoped `<style>` 块**（全局），暗底 `rgba(6,16,30,.82)` + 青边 + 浅字 `#eaf8ff` 即生效。scoped 块留注释说明原因。
- 验证：`vue-tsc --noEmit` 过滤 china-3d 零报错；全仓仅剩既有 `threejs-map/index.vue(13,3)` 无关告警。纯 CSS 改动，无逻辑影响。
