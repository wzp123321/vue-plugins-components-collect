### 追加：飞线「落地停顿」节奏修复
用户反馈：上一颗流星还没走完、下一颗就发射了（旧循环无缝连发）。
修复：updateFlyLine 周期改为 `1 + restGap`（mapConfig.fly.restGap=0.55），
停顿段整条熄灭；淡入淡出改不对称——起步 8% 柔和淡入、落地 3% 急熄，
流星亮着到达终点被涟漪「接住」。restGap 调 0 可回到旧的连续循环。

### 追加 2：飞线消失 bug 根因修复 + 轨道提亮（浏览器实测）
用户反馈：切换标牌后飞线消失、切飞线配置也无法恢复。
排查方法：playwright-core 驱动系统 Edge（headless）+ useFlyLines 临时探针
（attached=沿 parent 链走到顶判断是否仍连着 Scene）+ canvas 帧缓冲像素采样。
结论：
- 数据柱↔标牌切换本身不伤飞线（实测 attached 始终 true）。
- 真正根因：**theme watcher 重建 layer 时漏了 flies.build/orbits.build**。
  layer.build 内部 clear() 会把挂在其 root 上的飞线组连根摘除并 dispose，
  而重建清单只有 markers/pyramids/heat/c2d——切主题后飞线组 detached，
  之后 setVisible/setColor/setSpeed 全部作用于已脱离场景的对象，永远无法恢复。
修复：ChinaMap3D.vue 主题 watcher 补齐 `orbits.build(level)` + `flies.build(level, 0)`。
轨道配色提亮：trackColorNear #081D2E→#0F3049、trackColorFar #15496F→#20618F。
验证：修复前切主题 attached=false + 像素静止；修复后全流程 attached=true 且
弧区像素波动（采样窗口要足够长——restGap 停顿期弧区可能恰好没流星，属正常）。
调试代码已全部移除，vue-tsc 零错误。
复现脚本留在 C:/tmp/map-repro/（repro*.js，驱动本机 Edge，无需下载浏览器）。
